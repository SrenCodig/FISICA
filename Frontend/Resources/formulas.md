# Fórmulas del laboratorio

- **Caída libre:** h = ½gt²; v = gt.
- **Movimiento rectilíneo uniforme:** x = x₀ + vt.
- **Mesa de fuerzas:** ΣFx = Σ(F cos θ), ΣFy = Σ(F sin θ), a = |ΣF|/m.
- **Movimiento parabólico:** x = v₀ cos(θ)t; y = y₀ + v₀ sin(θ)t − ½gt².
- **Lanzamiento vertical:** hmáx = v₀²/(2g); tsubida = v₀/g.

En todos los ensayos g = 9.81 m/s² y se desprecia la resistencia del aire.
